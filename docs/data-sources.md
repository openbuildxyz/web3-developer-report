# 数据来源

本页用于集中说明报告中出现的数据来源、统计口径和外部参考。任何面向传播的结论，都建议回链到具体章节或本页，便于读者复核。

## 当前数据类型

| 类型 | 用途 | 说明 |
|---|---|---|
| 开源开发活动 | 统计开发者规模、月活跃、提交、任期和贡献频率 | 主要来自公开仓库与开发活动记录，需持续维护去重、生态归属和异常处理口径。 |
| 生态与技术栈分类 | 生成链、EVM/非 EVM、多链协作、生态重合度等分析 | 分类口径会直接影响生态排名和跨链指标，建议在年度报告中保留版本说明。 |
| 使用案例标签 | 分析 DeFi、ZK 等应用方向的开发者变化 | 标签可随着报告主题扩展，例如 AI、DePIN、游戏、钱包、稳定币等。 |
| 地理与社区信息 | 观察全球与华语开发者分布 | 需要谨慎处理隐私和推断误差，公开传播时建议只呈现聚合结果。 |

## 关于 Electric Capital 2025 年报告

Electric Capital 在 2025 年 11 月发布 [Announcing Open Dev Data](https://electriccapital.substack.com/p/announcing-open-dev-data)，说明从 2025 年开始，他们不再发布独立年度 Developer Report，而是把数据和方法迁移到持续更新的 Open Dev Data 平台。

他们给出的原因很直接：从 2019 年开始，数据管线已经扩展到数千个生态、数百万开发者和数亿次提交，接近实时地处理这些数据时，一年一次的 PDF 不再是合适的格式。新的平台会开源 taxonomy 和底层数据，让生态、研究者和数据团队自己构建分析、仪表盘和专题报告。

这也是本站继续做年度报告和华语报告的理由：Electric Capital 把底层数据公共化以后，行业仍然需要有人把数据翻译成可读的年度叙事、社区语境和本地问题。全球报告负责整理跨生态趋势，华语报告则补上中文开发者社区、职业路径和参与方式这些更具体的问题。
