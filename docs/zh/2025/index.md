# 2025 Web3 华语开发者调研报告

这是一份面向华语 Web3 开发者的社区调研报告。它关注的不只是“有多少人在写代码”，也关注开发者从哪里来、为什么进入 Web3、如何学习和求职、怎样参与开源，以及他们如何看待这个行业的机会与风险。

报告基于 220 份有效问卷，由 OpenBuild、GCC、登链、Creators、OpenCAS 联合发起，Web3insight.ai 提供数据分析支持。

## 主要发现

- Web3 对多数华语开发者来说，已经从“信不信”变成“值不值得押职业筹码”。样本中接近一半仍在 Web2 或校园、但持续观望 Web3；另一半已经全职或长期投入 Web3。
- 画像与普通工程师高度重叠：年龄主要集中在 20-35 岁，本科和硕士占比接近九成。真正拉开差距的不是学历，而是能否持续跟进英文一手信息并参与跨地域协作。
- Web3 的全球化没有消灭“位置”的意义，而是把它从办公城市变成职业策略。有人在内地二线/新一线城市为全球项目写代码，也有人向新加坡、香港、迪拜等枢纽靠近。
- 收入更像“中等偏上、波动更大”的工程师工作。固定薪资并不总是显著高于 Web2，但交易、外包、Airdrop、Grant 等非固定收入带来了想象力，也把更多风险推给个体。
- 技术栈没有脱离 Web2。前端、全栈 JS、Python、Java、Go 仍是基础盘，EVM 和 Solidity 是默认起点，Move、Solana、ZK 等更像进阶第二技术语言。
- 开源是 Web3 的基础设施，但华语开发者在核心仓库中的长期维护者仍然偏少。大家高度依赖开源，也愿意提交 Issue 或 PR，但持续维护、治理参与和许可证理解还有很大提升空间。
- 社区最需要补上的不是热闹，而是机会密度：更透明的岗位、合作机会、项目孵化、Grant/Bounty、导师制和可信学习路径。

## 样本概况

本次调研将开发者状态归并为五类：已从 Web2 转入 Web3、学生阶段已直接进入 Web3、仍在 Web2 工作并观望 Web3、在校学生并观望 Web3、已经或准备离开 Web3。

这个结构很接近新技术进入冷静期后的典型状态：多数人在观望，少数人已经下场，极少数人体验过再离开。它说明 Web3 已经不再只是情绪化叙事，而是一条需要认真评估的技术和职业路径。

对生态建设者而言，真正要争取的是那一大批“观望但未决”的人。他们已经跨过认知门槛，接下来需要的是更可信的学习路径、更透明的机会和更低噪音的社区环境。

## 教育与英语

样本中，本科和硕士占比接近九成，20-35 岁构成绝对主力。这并不说明 Web3 是“高学历限定赛道”，而是说明进入 Web3 的人，本来就大量来自主流软件工程师群体。

真正的差异往往出现在英文能力上。只会依赖翻译工具的人可以入门，但如果要进入协议核心、参与治理、跟全球团队协作，英文文档阅读、异步沟通、Issue/PR 讨论和会议表达能力会逐步变成硬门槛。

这也是华语 Web3 开发者最容易被低估的一点：技术能力之外，信息源和协作半径决定了很多机会能不能被看见。

## 地理与职业策略

Web3 的远程属性让开发者可以在内地二线/新一线城市，以美元或稳定币收入参与全球项目，这是一种典型的地理套利。

但地理位置并没有失效。走向管理层、协议核心或创业角色的人，往往更靠近新加坡、香港、迪拜等资金、合规和项目密度更高的枢纽城市。还有一部分开发者选择东南亚、日本等地的数字游民路径，获得自由的同时，也要承担更高的合规、税务和长期保障风险。

换句话说，Web3 的全球化并没有让所有位置变得一样，而是让“在哪里工作”变成了更主动的职业策略。

## 收入与风险

华语 Web3 开发者的收入结构比 Web2 更复杂。固定薪资仍然是基础，但交易、外包、Airdrop、Grant、Bounty 等非固定收入也会进入个人现金流。

这种结构一方面带来上行空间，另一方面也让个体承担了更多公司原本应该承担的波动风险。很多岗位以远程、合约、Token 激励或项目制形式存在，社保、长期福利、税务和合规安排并不总是清晰。

所以，对大多数人来说，Web3 更像一份“中等偏上、但波动更大”的工程师工作，而不是持续不断的暴富机器。判断一份机会时，不能只看名义薪资，还要把支付方式、币价波动、合规责任和团队稳定性一起算进去。

## 技术栈与公链偏好

Web3 并不是脱离 Web2 的全新技能树。前端、全栈 JS、Python、Java、Go 仍然是基础盘，Rust/C++ 更多出现在底层、高性能和部分链生态中。

EVM 与 Solidity 是最主流入口。对很多项目来说，Solidity 已经像“默认技能”，不再需要被特别强调。Move、Solana/Rust、ZK、跨链和数据基础设施则更像进阶第二技术语言：它们能带来技术溢价，但通常不是第一次入门的最低门槛。

从公链关注度看，Ethereum 仍是核心，Solana 和 Bitcoin 位于第二梯队，BNB、Sui 等生态紧随其后。华语开发者的关注结构与全球趋势大体一致，但在实际贡献深度上仍有提升空间。

## 动机入门与挑战

选择 Web3 的首要原因，已经从早期更理想化的叙事转向现实的职业算账：远程工作、灵活生活方式和更高薪资排在前面，“去中心化信仰”只占少数。

最有效的入门路径也比较清晰：读文档和源码，参加开源项目与黑客松，在社区里建立可信记录，然后获得第一份工作、Grant 或合作机会。相比“学完再进场”，Web3 更像需要边做边建立声誉的行业。

转型难点主要集中在四类：系统学习路径不足、工作机会不透明、合规和法律担忧、英语和理念门槛。退坑者也并不总是否定区块链技术本身，更多是对当前行业形态、项目稳定性和职业安全感失望。

## 开源参与

Web3 高度依赖开源组件，但真正长期维护项目的人仍然偏少。很多开发者会读源码、提 Issue、使用开源库，也有人提交 PR；但持续维护、参与治理、理解许可证和推进项目路线图的人还没有形成足够厚的基本盘。

与全球开发者调查相比，本次样本中提交过 Issue 或 PR 的比例并不低，说明华语开发者并不缺参与意愿。问题更多出在路径不清、时间不足、信心不足，以及不知道哪些项目适合新贡献者。

Web3 正在尝试用 Grant、Bounty、Token 和声誉激励重塑开源协作，但这些机制还在实验阶段。真正健康的开源生态，不只需要奖励短期任务，也需要支持长期维护者。

## 社区与从业环境

多数开发者至少偶尔参与社区活动，不少人会参加黑客松、技术分享和线上讨论。相比课程和工具，他们更期待社区提供就业/合作机会、项目孵化、资助入口和更可信的人脉网络。

从业环境的评价整体在“一般到满意”之间。大部分人短期内不打算回 Web2，但也有一部分人处于摇摆状态。行业的核心矛盾不在于绝对收入，而在于机会密度和不确定性之间的拉扯。

如果社区想真正留住开发者，就不能只做信息流和活动流，还要把学习、贡献、展示、机会匹配和长期支持连成闭环。

## 方法与局限

本次问卷不是严格随机抽样，样本主要来自 Web3 社区、微信群、Telegram 群、招聘渠道、黑客松和相关活动，存在自选择偏差。

问卷针对已在 Web3、观望中、学生、退坑等不同阶段设计了不同问题，不同分支问题的有效样本数并不完全一致。收入区间以美元为主，主观满意度也可能受市场行情、项目周期和个人预期影响。

因此，本报告更适合作为华语 Web3 开发者生态的结构化观察，而不是对全部开发者群体的精确统计。
