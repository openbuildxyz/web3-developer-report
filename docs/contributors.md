# 贡献者

感谢所有参与报告内容、图表、工程和发布维护的人。当前列表合并了全球报告与华语报告两个仓库的 GitHub 贡献者。

<ContributorGrid />

## 参与方式

- 内容贡献：补充报告章节、校对数据口径、修正图表描述。
- 数据贡献：提供可复核的数据来源、分类方法或生态标签。
- 工程贡献：优化站点、筛选器、图表呈现、自动化构建和发布流程。
- 传播贡献：帮助制作摘要、引用片段、社媒卡片和多语言版本。

欢迎通过 [GitHub 仓库](https://github.com/openbuildxyz/web3-developer-report) 提交 Issue 或 Pull Request。
